1. Problem & Objectives

• INDUSTRIAL DANGER: Conventional alarms act only after room saturation, lack live telemetry, and suffer false alarms from ambient drift.

• ENGINEERING GOAL: Create an air-gapped edge safety station that tracks baselines dynamically and actuates defenses with zero cloud reliance.

2. Atmospheric Sensing Core

• MQ-2 (Combustibles / GPIO 34): SnO2 sensor monitoring LPG, propane, methane, hydrogen, and smoke particles.

• MQ-135 (Air Quality / GPIO 35): Quantifies toxic contaminants including ammonia (NH3), CO2, and benzene.

• 16-PASS FAST ADC SMOOTHING: Bit-shifted digital oversampling (>> 4) eliminates analog noise without blocking CPU cycles.

3. Dynamic Baseline & Hysteresis

• ROLLING DRIFT TRACKING (EMA): Eliminates false alarms from ambient room drift:

Base = (0.99 × Base) + (0.01 × Live_ADC)
Threshold = Base + Margin [MQ2:+300 | MQ135:+250]

• 50-POINT HYSTERESIS: Prevents destructive mechanical relay chatter near trigger boundaries.

5. Operational State Machine (FSM)
STAGE 1: INIT / THERMAL WARMUP 0s - 30s
Heaters reach 200°C–300°C. Actuators locked idle. Clean air baselines calculated and locked.
STAGE 2: ARMED & TRACKING Nominal
Live ADC < Threshold. Fan OFF, Vent 0° (Closed). Baseline drifts continuously with ambient room air.
STAGE 3: ACTIVE DEFENSE Hazard Breached
Relay turns ON immediately. Servo opens to 90° (+250ms). Buzzer pulses at urgent 60ms rate.
6. Autonomous Dual Mitigation

• INSTANT RELAY EXHAUST (0 ms): Closes contacts instantly on threshold breach to activate extractor fans.

• STAGGERED SERVO (+250 ms): Deploys vent flap to 90°. The 250ms delay eliminates simultaneous current draw, preventing ESP32 brownout resets.

7. 5 Hz Master Sync Engine

• 200ms MASTER CLOCK: Sensor acquisition, OLED rendering, and dashboard polling run synchronously.

• 400 kHz FAST I2C: Lowers SH1106 draw latency from 100ms down to 25ms, avoiding CPU delays.

• PRE-ALLOCATED JSON: Reserved string buffers eliminate memory fragmentation and UI stalls.
